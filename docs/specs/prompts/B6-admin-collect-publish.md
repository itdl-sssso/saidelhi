B6 · Portal: collect and publish. Follow specs/RULES.md.

**Admin – Form builder** (desktop-first; phone = read-only preview)
- Top bar: name, "Draft of v4", "HI: 3 fields missing", Preview (phone, EN/HI), Test submission, Publish (blocked until EN+HI complete).
- Left: palette (number, text, date, time, dropdown, multi-select, yes/no, repeater, photo/file, section, help text).
- Centre: canvas, drag to reorder. Locked core fields with lock icon: samithi, date, venue, people served, volunteers, hours.
- Right, field settings: label/help EN+HI; required; min/max; show-if; cross-field rule ("≤ Cataract found"); warning threshold; KPI mapping ("Maps to spectacles_distributed" / "Custom"); Personal-data toggle (forces consent, "Excluded from dashboards and exports"); retention.
- Bottom drawer: Excel preview / WhatsApp question preview (chat bubbles, live) / validation summary.
- Dialogs: removing a KPI-mapped field; "Publishing creates v5; live links keep their version". No ID field type.

**Admin – Form templates:** per type: version, field count, EN/HI status, events using. Open / Duplicate / Versions / Preview / Download Excel. District: "Request a change" dialog; state sees a requests panel.

**Admin – Uploads:** stepper:
1. Type + download prefilled template (or "my own file" → Inbox).
2. Drop file.
3. Preview with red/yellow cells (EN/HI messages), "38 OK · 4 need fixing".
4. Load + download marked file.
5. Result "30 new, 8 updated, 4 rejected".
Re-upload → "No changes". History table.

**Admin – Centres:** public profile (name EN/HI, address, pin picker, centre number labelled "Shown publicly — use the centre's number"); weekly schedule editor; photos; public preview.

**Admin – Partners:** table (name, kind, city, events this year, internal contact) + add/edit dialog.

**Admin – Content:**
- List: type, EN/HI status, Draft/Scheduled/Published.
- Editor: EN/HI tabs, rich text, category, district, cover; link an event (inserts results card); schedule; preview. "Create from event". Thought for the Day calendar.

**Admin – Impact controls:** KPI public toggles; show/hide estimates; estimates table (district × year × type, source, entered by); tile preview.

**Admin – Migration:** source → map types → preview → import → redirects table (old→new). Report: imported / skipped / fix manually.
