A. /admin Overview. Admin shell. Greeting + scope. "Needs you" list first on phone: reports to approve → Approvals; camps without report (inline Resend link); inbox drafts to check; escalations (state only). KPI tiles for scope this month: activities, people served, volunteer hours, reporting rate (sparkline + delta). Next 14 days events table (date, title, samithi, pill). By seva type bars. Quick actions: Plan event, Upload file, Copy form link. Empty: "You're all caught up."

B. /admin/events/[id] Event detail (portal hub). Header: title, type, date, venue, samithi, district, big pill, primary action changes by status (Approve plan / Send form links / Approve report / Request changes), overflow (edit, postpone, cancel, view public page). Timeline: Draft → Awaiting approval → Planned → Event day → Awaiting report → Report submitted → Approved, with who/when ("Approved on WhatsApp by district coordinator, 20 Oct 9:12 AM"), Escalated branch. Form links panel: rows Report / Desk 2 / Public, sent to (masked), expiry, uses, last opened; copy, resend WhatsApp, QR dialog, extend, revoke; Add desk link. Disabled before plan approval with reason. Submission summary + source badge (Form/Upload/WhatsApp/Scan) + edit history. Public results preview. Attachment: register scan "Private · never published · deleted 17 Oct 2027". Follow-up count (restricted). Activity log. Show with sample eye camp.

C. /admin/inbox Review inbox. List tabs: For me · Escalated to state · Done; rows: source icon, masked sender, matched event or "No event matched", AI confidence pill (High/Check/Low), age. Item view split: left source (WhatsApp thread / sheet / scan with zoom, ID columns blurred "ID numbers are not read or stored"); right AI-filled draft, low-confidence fields marked icon+text with "Why?" ("Handwriting unclear"), event match selector. Actions: Approve into event, Save edits, Send to state team, Reject (reason sent on WhatsApp), Ask sender. Footer: "A person must approve before it counts." Phone: Source/Draft tabs.

D. /admin/links Form links. Filters: Active, Expiring 48h, Expired, Revoked; purpose; district; event. Table: event, purpose, sent to (masked or "QR poster"), created, expires, uses (1/1, 14/∞), last opened, OTP yes/no; copy, resend, QR, extend, revoke. Revoke confirm: "Anyone with this link will see 'This link is no longer active'." Never show token.

E. /f/[token]/form Form fill (eye camp report). Minimal header: event title, lang toggle, save status ("Saved on this phone · Not sent yet"). Sticky progress. Sections: About camp (samithi/date prefilled locked, venue, partner, sevadals, volunteer hours) · People (screened, male, female, under 18) · Spectacles (total + per power, live "63 of 63" check) · Cataract (found, referred ≤ found, surgeries "fill when known") · Attach register photo (private, IDs never read) · Follow-up list repeater (Personal data, consent required: name, age, gender, phone, locality only) · Notes · Review → Send report. Numeric keypad, steppers. States: offline queue, session expired (re-OTP, keep data), already sent (Edit until approved). One-handed at 375.
