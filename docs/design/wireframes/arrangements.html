Production notes

To build this we need

A lotus 3D model (petals as separate named meshes so they can rotate independently), a Baba figure or a photographic plate for the core, and one HDRI / light rig that ramps dark → bright. Model weight budget: under ~4 MB for mobile.

Fallbacks

No WebGL, reduced-motion, or slow connection → a pre-rendered image sequence of the four Act I states, and Act II as five static cards. No pinning, no snapping, same content, same order.

B · Full-bleed chapters
The home page becomes five full-height "chapters", each one image with a single line over it. Floating nav + dot rail. All supporting detail is one tap deeper, so the landing experience is nearly wordless.
